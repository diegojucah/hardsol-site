Inversor string, microinversor ou otimizador: o que muda no projeto

A escolha do inversor define rendimento sob sombra parcial, granularidade de manutenção e custo por watt.

Fotovoltaica · Equipamentos·por Engenharia HardSol·22 de jul. de 2026·5 min de leitura

String: mais conversão, menos granularidade

Inversor string trabalha o string inteiro como uma carga. Menos componentes e custo por watt menor — e uma sombra parcial derruba a produção do string todo (MPPT da série). Em telhado limpo, orientação única e sem interferência, costuma ser o melhor custo por kWh produzido.

String: mais conversão, menos granularidade

Inversor string trabalha o string inteiro como uma carga. Menos componentes e custo por watt menor — e uma sombra parcial derruba a produção do string todo (MPPT da série). Em telhado limpo, orientação única e sem interferência, costuma ser o melhor custo por kWh produzido.

Microinversor: um por módulo

Cada módulo tem seu MPPT. A sombra afeta só o módulo que recebe — não os demais. E o rendimento é acompanhado por painel, o que é uma vantagem real no pós-venda.

Otimizadores: meio termo

String + otimizador por módulo. Mantém o inversor central e recupera parcialmente o que a sombra desperdiça. Custo fica entre os dois.

Regra de decisão

  • Telhado limpo, orientação única — string
  • Sombras frequentes ou telhado com várias faces — microinversor
  • Projeto grande com rastreio de perdas por módulo — string + otimizador
