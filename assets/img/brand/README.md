# Logos e marca

Coloque aqui os arquivos do logo. Nomes esperados (só preencher o que existir):

| Arquivo | Uso |
|---|---|
| `hardsol.svg` | Logo da **HardSol** (header, rodapé) |
| `hardev.svg` | Logo da **HardEv** (área própria) |
| `favicon.svg` | Ícone da aba do navegador |
| `og.png` | Imagem 1200×630 para compartilhamento (Open Graph) |

**Prefira SVG.** Motivo prático: eu consigo ler o arquivo e puxar as cores exatas do
logo para alinhar o site — com PNG/JPG eu só consigo embutir, sem conferir a cor.

Se o logo vier em PNG, use pelo menos **2× o tamanho de exibição** (ex.: 240 px de
altura para aparecer com 120 px) e com fundo transparente.

Sugestões de cor (as atuais do site):

- Âmbar `#FFBC3B` (hover `#FFCD6E`)
- Azul `#041581` (hover `#2E36A8`)
- Texto `#1A1A37` · fundo `#FFFFFF`

## Onde o logo entra

- Header e rodapé de **todas** as páginas
- Favicon (`favicon.svg`)
- JSON-LD (`Organization.logo`)
- Open Graph / Twitter Card (`og.png`)
